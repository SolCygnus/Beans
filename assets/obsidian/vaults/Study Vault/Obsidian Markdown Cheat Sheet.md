# Obsidian Markdown Cheat Sheet

Obsidian is a powerful note-taking app that leverages Markdown for formatting.
Below is a quick guide to help you get started with Obsidian and Markdown.

---

## 📌 What is Obsidian?

Obsidian is a knowledge management and note-taking app that stores your notes in
plain text Markdown files. It allows for:

- Local-first storage (no cloud requirement)
- Bidirectional linking between notes
- Graph visualization
- Customizable themes and plugins

---

## 💡 How to Use Obsidian Effectively

Here are some ideas on how to make the most out of Obsidian:

- **Daily Notes**: Keep a journal or log of daily activities.
- **Knowledge Management**: Organize topics, books, and ideas in a structured way.
- **Zettelkasten**: Create a personal knowledge database with interlinked ideas.
- **Project Management**: Track tasks and projects using Markdown and plugins.
- **Study Notes**: Summarize key learning points and link related concepts.

## 📖 Markdown Syntax Basics

### 📝 Text Formatting

```markdown
**Bold** → **Bold**
*Italic* → *Italic*
~~Strikethrough~~ → ~~Strikethrough~~
`Inline Code` → `Inline Code`
```

### 🔗 Links & Images

```markdown
[Obsidian Website](https://obsidian.md)
![Image Alt Text](image.png)
```

### 🏷️ Internal Links (Obsidian-Specific)

```markdown
[[Note Name]] → Links to another note
[[Note Name#Heading]] → Links to a specific heading in another note
```

### 📌 Headings

```markdown
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
```

### 📋 Lists

```markdown
- Bullet List Item 1
- Bullet List Item 2
  - Nested Item

1. Numbered List Item 1
2. Numbered List Item 2
```

### ✅ Checkboxes (Task Lists)

```markdown
- [ ] Incomplete Task
- [x] Completed Task
```

### 📜 Quotes & Code Blocks

````markdown
> This is a blockquote

```text
This is a code block
```
````

### 📊 Tables

```markdown
| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Data 1   | Data 2   | Data 3   |
| Data 4   | Data 5   | Data 6   |
```

### 🎵 Embedding Media (Obsidian-Specific)

```markdown
![[filename.png]] → Embeds an image or file
```

### 🎯 Callouts (Obsidian-Specific)

```markdown
> [!note] This is a note
> Some additional information here
```

- **Note:** `> [!note]`

- **Warning:** `> [!warning]`

- **Important / Hint:** `> [!important]` (or `> [!hint]`)

- **Success / Done:** `> [!success]` (or `> [!done]`)

- **Question / FAQ:** `> [!question]` (or `> [!faq]`)

## 🚀 Obsidian Shortcuts

| Action | Shortcut |
| -------- | ---------- |
| Open Command Palette | `Ctrl + P` / `Cmd + P` |
| Create New Note | `Ctrl + N` / `Cmd + N` |
| Search Notes | `Ctrl + Shift + F` / `Cmd + Shift + F` |
| Toggle Sidebar | `Ctrl + E` / `Cmd + E` |
| Open Graph View | `Ctrl + G` / `Cmd + G` |

---

## 🔥 Popular Obsidian Plugins

- **Dataview**: Query and filter your notes like a database.
- **Calendar**: Add a calendar view to your notes.
- **Templater**: Automate repetitive note-taking tasks.
- **Kanban**: Use a Trello-like board for tasks and projects.
- **Advanced Tables**: Improve Markdown tables with better formatting.

---

## 🎯 Pro Tips

- Use `[[Links]]` to connect notes for better organization.
- Take advantage of **tags** (`#tag`) for easy searching.
- Use the Graph View to visually explore your knowledge base.
- Customize Obsidian with themes and CSS for a personalized look.
