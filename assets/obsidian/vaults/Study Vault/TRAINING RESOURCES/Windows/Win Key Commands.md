
## Managing Virtual Desktops:

==**Opens Task View, allowing you to see all open windows and virtual desktops.**==
	```Windows Key + Tab```
	

==**Creates a new virtual desktop.**==
	```Windoys Key + Ctrl + D```
	

==**Switches between virtual desktops**==
	```Windows Key + Ctrl + Left/Right Arrow keys```

	
==**Closes the current virtual desktop**==
	```Windows Key + Ctrl + F4```
	
	
==**Quickly switches to the corresponding virtual desktop (e.g., Windows key + 1 - for Desktop 1)**==
	```Windows Key + 1/2/3/4```


==**Change Active window**==
	```Alt + Tab Key```
